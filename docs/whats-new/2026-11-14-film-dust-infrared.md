### Film dust removal from the scanner's infrared pass
- A film scanner's RGBI file (VueScan "64-bit RGBI", SilverFast HDRi: RGB plus an infrared pass) opens as an opaque picture with the infrared pass kept beside it. Before, the pass was read as transparency: the photo was see-through and every dust speck a hole.
- **Remove ▸ Remove Film Dust** fills in the dust, hairs and scratches that pass shows, before the picture is converted, as the scanner's own infrared cleaning does: dust blocks infrared while the film's dyes pass it, so the pass is a map of the marks. It is a develop setting, so it copies, syncs and exports with the photo. **Film Dust Sensitivity** sets how far below its local level the pass must fall to count, **Film Dust Expand** grows (or shrinks) each mark before it is filled, and **Show infrared mask** tints what will be filled.
- **Show as Mask** turns the same marks into a mask of the photo instead, for the brush and for **Fill Selected Mask** / **Generate into Selected Mask** (a fibre too large to fill in smoothly, say).
- A scan without the pass (a camera scan, an 8-bit TIFF) keeps **Film Dust Spots**: the picture is searched for the sharp bright marks on smooth areas and each gets a spot filled from its surroundings.
